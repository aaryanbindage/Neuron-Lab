# Neuron Lab

A visual, hands-on introduction to neural networks, built for beginners. Everything runs in the browser with plain HTML, CSS and JavaScript. There are no dependencies and no build step.

- **One neuron** (`index.html`, tab 1): turn the weights, bias and activation function and watch the arithmetic update live.
- **Network lab** (`index.html`, tab 2): build a small network, pick a pattern such as XOR or a ring, and watch it train.
- **How it works** (`how-it-works.html`): a plain-language explanation of neurons, layers and training.

## Run it

Open `index.html` in a browser. Fonts load from Google Fonts, so it looks best online.

## Published page
